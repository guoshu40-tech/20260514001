# 猜數字遊戲 (1-1000)

[🚀 線上預覽](https://guoshu40-tech.github.io/20260514001/)

一個精美的猜數字遊戲，包含提示、次數記錄與動畫效果。

## 功能特點

- **多種模式**：單人挑戰、雙人對決、以及對抗電腦 (AI)。
- **難度分級**：簡單、中等、困難，以及自定義範圍。
- **視覺化提示**：動態數線顯示目前可能的範圍。
- **統計系統**：記錄最佳分數、勝場次數與對戰歷史。
- **精美介面**：使用 Tailwind CSS 與 Framer Motion (Motion) 打造流暢動畫。

## 如何執行

### 前置需求

- Node.js (建議 v18 以上)

### 執行步驟

1. **安裝依賴**：
   ```bash
   npm install
   ```

2. **啟動開發伺服器**：
   ```bash
   npm run dev
   ```

3. **建置生產版本**：
   ```bash
   npm run build
   ```

## 技術棧

- React 19
- Vite
- Tailwind CSS
- Lucide React (圖示)
- Motion (動畫)
